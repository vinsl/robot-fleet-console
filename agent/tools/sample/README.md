# Sample warehouse DXF

`warehouse.dxf` is a 60 m x 40 m warehouse drawing (millimetres, DXF R2010) used to exercise the
site configuration import of the console without a real floor plan.

## Content

| Layer | Content |
| --- | --- |
| `WALLS` | Closed outer rectangle, two partition lines, one door arc |
| `RACKS` | Twelve inserts of block `RACK` (3 m x 1 m, drawn on layer `0`) |
| `MACHINES` | Two closed polylines, two pillars (circles) |
| `DIMENSIONS` | Dimension lines and a `60 m` text |
| `NOTES` | One MTEXT note |

The `TEXT` and `MTEXT` entities are not geometry for the site map: the importer counts them by type as
ignored and the import report shows the count. The dimension lines are `LINE` entities on layer
`DIMENSIONS`; the importer reads them like any line, and the layer mapping drops them because the role of
the layer is `ignore`.

## Regenerating

The generator writes the same bytes on every run and for every Python hash seed. The test suite
compares the committed file with the generator output byte for byte, and a regression test
regenerates the file under hash seeds 0 to 7.
